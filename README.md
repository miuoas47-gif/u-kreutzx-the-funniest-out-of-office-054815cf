A deterministic generator that writes the funniest out-of-office auto-reply
you have ever received: your inbox is minded by Dave, a goldfish with no
thumbs, no password and no concept of email; your message joins a queue run
by a self-aware auto-reply; and the reply itself has been promoted to acting
manager. No network, no clock, no unseeded randomness — the same run always
writes the same reply.

## Run it

```sh
python3 main.py
```

This writes `out_of_office.txt` into `$MAKEFUN_OUTPUT_DIR` (or `./output`
when unset) and exits 0.
